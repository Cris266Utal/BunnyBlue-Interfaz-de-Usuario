# BunnyBlue-Interfaz-de-Usuario
Interfaz web (HTML5, CSS3 y JavaScript) del sistema interno de gestión de pedidos de BunnyBlue. Incluye login con bloqueo, perfiles admin y user, registro y edición de pedidos con cálculo en CLP, CRUD de productos y procesamiento de pedidos en dos pasos. Evaluación 3, Interfaces de Usuario, Universidad de Talca.
